# URL Redirect Checker

A Python script to check and validate URL redirects behavior.

## Description

This tool helps you verify URL redirects by following redirect chains and reporting their status codes, final destinations, and any potential issues.

## Features

- Follows URL redirect chains
- Reports HTTP status codes
- Validates final destination URLs

## Usage

```bash
# Create and activate virtual environment
python -m venv venv

# Activate on Windows
venv\Scripts\activate

# Activate on macOS/Linux 
source venv/bin/activate

# Install dependencies

pip install -r requirements.txt
python main.py
```
